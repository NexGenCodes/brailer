# Settings — Studio account

An account settings screen for a design-studio user inside the same product
family as the pencil storefront.

- Page heading "Account settings" with an h2.
- Two cards: "Profile" (name, email, save button) and "Shipping" (address
  lines, save button).
- A small nav row on the left flank on desktop: Profile, Shipping, Billing,
  Notifications.
- A danger zone: a red-bordered card explaining that deleting the account is
  final, with a red button.
- Desktop 1440 (nav column beside stacked cards), mobile 390 (nav folds above).
